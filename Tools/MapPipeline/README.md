# MapPipeline (этап M2)

Офлайн-конвейер: OpenStreetMap + Copernicus DEM → тайлы мира в масштабе 1:5 → импорт в Unreal.

План:
1. `fetch.py` — скачать региональные выгрузки (.pbf) Сибирского и Дальневосточного ФО и тайлы DEM вдоль маршрута.
2. `corridor.py` — выделить трассы по `ref` (Р-255, Р-258, Р-297, А-370), построить коридор ±3 км.
3. `project.py` — проекция и сжатие 1:5 (по горизонтали и вертикали, с ограничением уклонов трассы ~10%).
4. `tiles.py` — нарезка на тайлы 2×2 км: карта высот (16 бит), сплайны дорог (JSON), землепользование, POI.
5. Импорт в UE: Landscape + сплайны дорог + PCG.

Сырые данные (`data/`) и результат (`out/`) в git не попадают.
