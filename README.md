# Перегон: Новосибирск — Владивосток

Инди-автосимулятор с выживанием и песочницей на Unreal Engine 5.8. Перегоняешь старую машину
через всю Сибирь и Дальний Восток по реальной трассе (масштаб 1:5, ~1 170 км), чинишь её
и дорабатываешь в дороге. PSX-графика с современным светом и объёмной погодой.

Подробно: [дизайн-документ](docs/GDD.md) · [архитектура](docs/ARCHITECTURE.md) · [дорожная карта](docs/ROADMAP.md)

## Статус: M1 — первая играбельная версия

- Своё ядро физики машины `VehicleSimCore` (C++17): мотор, сцепление, КПП, дифференциал, шины Пасейки
  с релаксацией, подвеска, тормоза с перегревом, расход, температура, износ деталей.
- Генератор трассы `RoadGenCore` (C++17): прямые, переходные кривые и дуги, профиль с уклоном ≤ 6%,
  рельеф коридора, сёла, АЗС, кафе. Тестовый участок «Новосибирск → Заречный», 15 км.
- Мир дороги стримится чанками по 250 м: асфальт с разметкой, обочины, кюветы, лес, ЛЭП, столбики,
  километровые знаки, деревенские дома с заборами, АЗС (заправка за деньги), кафе (ночлег и сохранение).
- Главное меню, новая игра (сид мира, уровень помощников, цвет машины), пауза, настройки камеры и графики,
  сохранение/продолжение, смена дня и ночи.
- Процедурные PSX-текстуры (без картинок в репозитории), салон, вид от 1/3 лица, пешеход.
- 76 автотестов ядер в CI.

## Запуск

Нужно: **Unreal Engine 5.8**, **Visual Studio 2022/2026** с «Разработкой игр на C++» и .NET Framework 4.8 SDK.

1. Клонировать репозиторий (с Git LFS).
2. ПКМ по `Peregon.uproject` → *Generate Visual Studio project files*.
3. Открыть `Peregon.uproject` → *Yes* на вопрос о сборке модулей.
4. При первом запуске редактор сам создаст материалы `Content/Peregon/Materials/M_PSX2` и `M_PSX2_Glass`
   (модуль `PeregonEditor`, в Output Log строки `[Peregon] Материал ... создан`). Их стоит закоммитить.
5. Нажать **Play**. Откроется главное меню на фоне трассы.

Меню паузы — **Tab** (в редакторе Esc останавливает Play; в собранной игре работает и Esc).

## Шрифты

## Управление

Игра начинается пешком рядом с машиной: подойдите к водительской двери, посмотрите на неё и нажмите **E**.
Пауза, сохранение и настройки — **Tab** / **Esc**. На АЗС подгоните машину к колонке, выйдите и нажмите E на колонке.
В кафе можно сохраниться, а ночью — переночевать до утра.

**Пешком**

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Ходьба / бег | WASD / Left Shift | левый стик / L3 |
| Обзор | мышь | правый стик |
| Прыжок | Space | A |
| Взаимодействие (двери, капот, багажник, бензобак) | E / F / ЛКМ | X |
| Вид 1-е / 3-е лицо | C | R3 |

**В машине**

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ / тормоз | W / S | RT / LT |
| Руль | A / D | левый стик |
| Обзор (из салона — поворот головы) | мышь | правый стик |
| Нажать на деталь салона (ключ, фары, ручник, бардачок, двери) | ЛКМ | A |
| Стартер (держать) | R | Y |
| Передача вверх / вниз | E / Q | RB / LB |
| Сцепление | Left Shift | X |
| Ручник (держать) / стояночный тормоз | Space / P | B / D-pad ← |
| Фары | L | D-pad ↑ |
| Выйти | F | D-pad ↓ |
| Автомат / механика | G | View |
| Вид 1-е / 3-е лицо | C | R3 |
| Поставить на колёса | Backspace | Menu |
| Подробная телеметрия | F3 | — |

Машина стоит на стояночном тормозе — перед поездкой опустите его (**P** или рычаг между сиденьями).
В режиме «автомат» тормоз на месте включает заднюю.
