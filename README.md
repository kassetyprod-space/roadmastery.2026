# Перегон: Новосибирск — Владивосток

Инди-автосимулятор с выживанием и песочницей на Unreal Engine 5.8. Перегоняешь старую машину
через всю Сибирь и Дальний Восток по реальной трассе (масштаб 1:5, ~1 170 км), чинишь её
и дорабатываешь в дороге. PSX-графика с современным светом и объёмной погодой.

Подробно: [дизайн-документ](docs/GDD.md) · [архитектура](docs/ARCHITECTURE.md) · [дорожная карта](docs/ROADMAP.md)

## Статус: M0 — ядро физики

- Своё ядро физики машины `VehicleSimCore` (C++17, без зависимостей): мотор, сцепление, КПП,
  дифференциал, шины Пасейки с релаксацией, подвеска, тормоза, расход, перегрев, износ деталей.
- 29 автотестов «паспорта» машины в CI.
- Прототип в UE: машина-«коробка», испытательный полигон с разными покрытиями, отладочный HUD.

## Запуск

Нужно: **Unreal Engine 5.8**, **Visual Studio 2022** с компонентом «Разработка игр на C++».

1. Клонировать репозиторий (с Git LFS: `git lfs install` до клонирования).
2. ПКМ по `Peregon.uproject` → *Generate Visual Studio project files*.
3. Открыть `Peregon.sln`, конфигурация **Development Editor**, собрать (или просто открыть `.uproject` — UE предложит собрать сам).
4. В редакторе: *File → New Level → Empty Level* → **Play**. Режим игры подхватит полигон, небо и машину сам.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ / тормоз | W / S (стрелки) | RT / LT |
| Руль | A / D (стрелки) | левый стик |
| Стартер (держать) | R | Y |
| Передача вверх / вниз | E / Q | RB / LB |
| Сцепление | Left Shift | X |
| Ручник | Space | B |
| Автомат / механика | G | View |
| Камера | C | правый стик (нажать) |
| Поставить на колёса | Backspace | Menu |
| Зажигание вкл/выкл | I | — |

В режиме «автомат» тормоз на месте включает заднюю. В «механике» без выжатого сцепления передача не включится.

## Тесты физики (без Unreal)

```bash
cmake -S Tests/VehicleSim -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/vsim_tests
```
